# StayFlow

호텔 운영 흐름(Customer → PMS → Kiosk)을 통합한 호텔 운영 플랫폼 프로젝트입니다.

StayFlow는 고객 예약, PMS 운영, 키오스크 셀프 체크인을 하나의 시스템으로 연결하는 것을 목표로 개발한 호텔 운영 플랫폼입니다.

---

# 프로젝트 소개

StayFlow는 호텔 운영 흐름을 통합 관리하기 위한 웹 기반 호텔 운영 플랫폼입니다.

고객 예약 → PMS 운영 → 키오스크 체크인 흐름을 하나의 시스템으로 연결하여 실제 호텔 운영 프로세스를 구현했습니다.

---

# 기술 스택

## Frontend

- React
- Vite
- Tailwind CSS
- Material UI (MUI)
- Axios
- React Router

## Backend

- Spring Boot
- Java 21
- Spring Data JPA
- PostgreSQL
- Hibernate

# 주요 기능

## 고객 예약 사이트

- 객실 조회
- 객실 예약
- 예약 조회
- 예약 취소

## PMS 관리자 시스템

- Dashboard 운영 현황
- 예약 관리
- 체크인 / 체크아웃
- 예약 검색 / 상태 필터
- 객실 상태 관리
- 객실 청소 완료 처리
- 객실 상태 변경

## 키오스크

- 예약 조회
- 셀프 체크인
- 체크인 완료 화면
